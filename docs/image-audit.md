### 3. `docs/panduan-mulai.md` (getting started guide) — HAS ISSUES

**6 image references** using `../bukti/<filename>.jpg` paths.

| Line | Path referenced | File exists? | Works in repo? | Issue |
| --- | --- | --- | --- | --- |
| 95 | `../bukti/01-tim-terdaftar.jpg` | Yes | **Yes** (GitHub resolves) | Works because GitHub renders md from `docs/` dir, and `../bukti/` goes up to repo root then into `bukti/` — **wait, `bukti/` is inside `docs/`, not at repo root** |
| 129 | `../bukti/K01-v5-akhir.jpg` | Yes | **No** | Same issue |
| 147 | `../bukti/K03-v2-lolos.jpg` | Yes | **No** | Same issue |
| 175 | `../bukti/panel-kendali.jpg` | Yes | **No** | Same issue |
| 206 | `../bukti/K16-draf.jpg` | Yes | **No** | Same issue |
| 222 | `../bukti/K16-kirim-ditolak.jpg` | Yes | **No** | Same issue |

**THE PROBLEM:** The file `docs/panduan-mulai.md` lives at `docs/panduan-mulai.md`. The image path `../bukti/01-tim-terdaftar.jpg` resolves as:
- `docs/` → go up one level (`..`) → repo root → `bukti/` → file

But the `bukti/` folder is at `docs/bukti/`, NOT at the repo root. There is no `bukti/` folder at the repo root.

**On GitHub repo view:** When viewing `docs/panduan-mulai.md` on GitHub, the relative path `../bukti/01-tim-terdaftar.jpg` resolves to `github.com/fajaraji/runut-tencent/blob/main/bukti/01-tim-terdaftar.jpg` — which does NOT exist. The images are at `github.com/fajaraji/runut-tencent/blob/main/docs/bukti/01-tim-terdaftar.jpg`.

**Fix:** Change `../bukti/` to `bukti/` in `docs/panduan-mulai.md` (6 occurrences).

## GitHub Pages configuration notes

- **Pages source:** The repo has no `.github/workflows/` or `_config.yml`. GitHub Pages is configured in the repo settings to serve from the `/docs` folder on the `main` branch.
- **Base path:** Since the repo name is `runut-tencent` and Pages serves user/org pages at `fajaraji.github.io/runut-tencent/`, there is no base path prefix needed for relative links within `docs/`. The `index.html` uses relative paths like `bukti/...` and `data/...` which resolve correctly.
- **No absolute paths:** None of the deployed files use absolute paths starting with `/`. This is correct — absolute paths would break on Pages because they'd resolve to `fajaraji.github.io/bukti/...` instead of `fajaraji.github.io/runut-tencent/bukti/...`.

---

## Conclusion

Only **one fix** is needed: change `../bukti/` to `bukti/` in `docs/panduan-mulai.md` (6 occurrences on lines 95, 129, 147, 175, 206, 222). Everything else is correct.
