# Runut Cepat (WorkBuddy Expert)

Mode satu agent dari Runut untuk uji live 90 detik. Memakai MCP server dan aturan kode yang sama dengan tim `runut-tim`, tapi tanpa tahap penyusun dan pemeriksa terpisah. Pemeriksaan isi jawaban dilakukan kode lewat `catat_jawaban`.

Baca [instruksi agen](agents/runut-cepat.md) untuk melihat alur satu agen. Cara memasang server dan expert ada di [panduan proyek](../../README.md).
